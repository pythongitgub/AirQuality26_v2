# AQ26 GitHub research-grade expansion patch

This patch expands the GitHub weekly run toward a research-grade controlled-review harvester.

Adds:
- Recursive Google Drive inventory
- Missing-date / missing-stream backfill planner
- Evidence priority scoring for official filings and news
- Research-method alignment based on satellite + ground + epidemiology + digital-twin best practice
- Expanded report summary and evidence gates

Still not a causal attribution engine:
- Satellite products are catalogued, not yet extracted into pollutant grids
- Official filing relevance remains candidate/probable until reviewed
- Health interpretation requires correct averaging-period comparators and exposure context
